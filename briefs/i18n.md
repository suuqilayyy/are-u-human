/goal 给 are u human 加一套中英双语切换，并把全部界面文字翻成中文。

背景：这是 CPX 2026 Track 2 黑客松作品（反向 UX：一个“证明你是人类”的验证流程），今天 13:00 截止，评委在展位现场体验。现在页面全是英文，我们想在演示时能切成中文。项目在 /Users/yaobii/Developer/are-u-human，纯静态 HTML + 原生 JS，没有构建工具。体验顺序写在 flow.js 的 ORDER 里：index.html → start.html → face.html → stage2.html → stage.html?s=3 → jury.html → pass.html → forum.html，这些页面都要覆盖。

要做的：
1. 一个共享的 i18n.js（每页用 <script src> 引入）。语言来自 URL 参数 ?lang=zh|en，记进 localStorage，后续页面跳转保持同一语言；默认英文。翻页时 flow.js 跳转要带上当前语言。
2. 静态文字用 data-i18n 等属性标记；JS 里拼出来的文字（比如 stage2.html 的题库 BANK、判定 V(...) 的标签、face.html 的提示句）改成 t('key') 取值，带数字的用占位符，如 t('verdict.picked',{pct}).
3. 词条放在 i18n/en.json 和 i18n/zh.json（或一个 JS 文件，按你判断，只要不需要构建、file 打开以外用 http server 能跑）。
4. 中文翻译交给 Gemini：本机有 gemini CLI（/opt/homebrew/bin/gemini）。把 en 词条整份交给它翻，要求：这是一个讽刺“AI 验证人类”的作品，语气冷静、官方、略带荒诞，像真实系统提示；按钮和标签用简短的中文界面用语（参考 Apple、飞书的中文界面），不加句末句号；数字和单位保持；题目里的“Kiki / Bouba”保留原文。翻完你通读一遍，明显不通的改掉。
5. 页面上加一个不显眼的语言切换（EN / 中文），放在 start.html 和每页右上角都可以，按你判断；不要做成说明文字。
6. 中文字体：tokens.css 里的字体栈补上 "PingFang SC","Noto Sans SC" 之类的中文回退。中文比英文短或长时，检查按钮、卡片、标题在手机宽度（375px）下不溢出、不难看地折行。

边界：stage2.html、tokens.css 等有未提交的改动，那是我们刚做的，在它们之上改，不要还原。assets/stage2/ 和 stage2-photos.html 是另一个任务在用，不要动。不要提交或推送 git。中途不用停下来问，按判断做，理由写在报告里。

完成条件：用 python3 -m http.server 起服务，以 ?lang=zh 从 start.html 一路翻到 forum.html（可以用 "]" 键跳页），每页可见文字都是中文、控制台无报错；?lang=en 时和改之前一致。报告里列出覆盖了哪些页面、还有哪些文字没覆盖（比如图片里的字），并贴出你用来检查遗漏英文的命令和输出。
