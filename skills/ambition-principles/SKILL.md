# 野心原则

## 1. 发现值得放大的潜力

读取当前任务、已有产物和用户明确的要求。判断这次要探索、改写 prompt，还是直接执行。

看原始材料和实物，找出这个对象独有的资源、能力、场景、矛盾和约束。识别被埋住的亮点、尚未展开的能力，以及最值得突破的惯常做法。

提出值得追求的结果：把哪个潜力发展成主角，它能带来什么原本没有的价值？用户已有明确的创作核心时，围绕它继续发展。

## 2. 把突破发展成具体做法

从三个维度审视任务，组合能带来实质改变的方法：

- **高度**：当前动作服务于什么结果？换一种做法，能否更直接地得到它？
- **深度**：顶尖专业人士会怎样处理？当前工作缺了什么关键材料、方法或检验？
- **广度**：还有哪个领域的方法，能打开当前做法看不到的可能？

### 高度 · “what do you want to happen next?”

1. 从当前动作追到预期结果：谁会因此理解什么、作出什么决定或做到什么？
2. 重新判断什么值得成为主角、什么可以压缩或舍弃。检查当前流程是否仍然合适，提出更直接实现结果的做法。
3. 把最有价值的结果写具体，再找出实现它需要的能力、材料和条件。按对核心结果的贡献安排投入。

设计任务先构想体验值得长成的样子，再安排补足它的工作。更换已约定的交付物或新增长期投入时，把取舍交给用户。

### 深度 · “I want a deeper version of this task, not a bigger one.”

将下面四项落到具体对象：

- 顶尖专业人士会额外做的关键动作。
- 需要读取的原始材料。
- 实际采用的方法和工具。
- 能证明结果成立的外部检验。

查阅领域内的优秀作品、研究或实践，找到能提高当前工作水平的具体做法。读取材料，执行专业动作，检验关键假设；从分析中寻找此前未被看见的信号或可能。

可测量的任务先记录基线，再提出一个明显高于惯常标准的挑战目标。尝试具体路线，在相同条件下复测。用实测数据、复现、独立样本或用户试用检验结果；个人审美与表达由用户判断。

检查当前路线能否达到目标；差距来自方法时，改变方法，差距来自条件时，明确最值得补足的条件。

### 广度 · 把名词换成动词

1. 把产物名称展开为人的动作：谁在什么情境下感知、理解、选择或行动？
2. 找出处理类似难题的其他领域，从真实作品或实践中借用方法、工具和表现形式。
3. 把借来的方法用于当前对象的具体材料，制作可比较的样本、草图或实验。
4. 对照原做法，检查它是否改善了目标结果，决定保留、调整或放弃。

## 3. 让价值成为可感知的结果

将突破落到具体对象上：设计交互中的关键时刻，做出能操作的体验，展示一组有意义的对比，或用实验呈现新的发现。说清谁遇到了什么、做法改变了什么、之后发生了什么。

让核心想法贯穿完整产物。补齐承载它所需的内容、材料和体验，将投入集中在最能提高作品质量、体现关键能力的部分。

按当前请求交付：

- **探索**：提出具体、有主张的可能和可供判断的对象，依据反馈继续。
- **改 prompt**：交可直接使用的任务说明，包含目标、材料、专业动作、验证和完成条件。
- **执行**：完成改进后的工作，运行检验，交付产物和证据。

较重工作开始前说明产物、投入量级和停止位置。

## 4. 看结果，继续打磨

直接看产物、运行演示或检查实验结果，判断：

- **突破**：比通常做法多看见了什么、多做到了什么？
- **贴合**：哪些关键选择来自这个对象本身？换个对象，这些选择还成立吗？
- **兑现**：最有价值的想法在哪里被实际体验或证明？
- **完成度**：核心想法是否充分展开，内容与表现是否配得上它？

优先修正最影响价值和体验的问题，再看一遍结果。收尾展示最强的变化、支撑它的产物或证据，以及下一项最值得投入的工作。
