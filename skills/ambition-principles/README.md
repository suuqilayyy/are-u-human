# 野心原则 · Ambition Principles

发现被忽略的潜力，提出值得追求的突破，组合高度、深度、广度的方法把它做出来，让人直接体验它的价值，再根据结果打磨。

## 使用

在支持 Agent Skills 的工具中加载本目录，调用 `$ambition-principles`，附上当前任务或 prompt。例如：

```text
$ambition-principles 帮我把这份研究计划做得更深入，找出值得验证的问题和具体方法。
```

支持共同探索、改写 prompt 和直接执行。执行指令见 [SKILL.md](SKILL.md)。

## 来源

方法来自 Felix Rieseberg 的 [How to be more ambitious: A tutorial for humans with models](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/)（2026-10-13）。本技能将文章中的 Altitude、Depth、Range 转化为可执行流程，保留两句英文原话。

实现参考了 [RoboNuggets / be-ambitious](https://github.com/robonuggets/be-ambitious)。

设计还借鉴了两份技能：

- **tasteskill v2 · design-taste-frontend**：从对象自身的材料生长想法，借助优秀实践打开选择空间，将核心概念做成可体验的作品，并直接检查实际产物。
- **Yaobii · portfolio-launch（作品集发布会原则）**：发现被埋住的亮点，把它发展成核心体验，识别最值得补足的投入，并通过具体场景呈现价值。
