**个人 AI 记忆系统 v1 方案简介**

**目标**：让 AI 助手长期记住"我是谁、做过什么、偏好什么",跨会话、跨工具复用,不再每次从零开始。

**核心设计**
1. **采集**:从对话记录、笔记等来源增量导入,统一成带时间戳和来源的文本记忆条目。
2. **存储**:本地优先,SQLite 加向量索引,同时保留原文,便于追溯和手动编辑。
3. **提炼**:定期用 LLM 把零散条目归纳为稳定的"事实/偏好/事件",合并重复,标记过期。
4. **检索**:综合语义相似度、时间新近度和重要性打分,取前 N 条注入提示词。
5. **隐私**:数据留在本机(模型调用除外),任意记忆可查看、修改、删除。

**v1 范围**:仅支持文本、单用户,通过命令行或 API 接入。图谱、多模态、多端同步留到后续版本。

**希望合作者重点评审**:提炼策略与检索打分权重。
