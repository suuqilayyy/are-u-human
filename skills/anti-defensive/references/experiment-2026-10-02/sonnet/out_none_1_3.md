我先对比 3 个候选 3D 生成后端，再推荐一个适合你黑客松 demo 的。

**做法**：每个后端用同一组 5 个物体（风格和复杂度有差异）生成模型，保证对比公平。

**对比维度**：
- 生成速度（demo 现场等不等得起）
- 模型质量（几何、纹理、是否可直接预览）
- 稳定性（失败率、是否需要重试）
- 接入成本与费用（API 是否简单、有无免费额度）

**产出**：一张对比表，加上我的推荐和理由。生成的文件都放在当前工作目录 `exp` 下，不会改动其他位置。

**需要你知道的**：
- 调用各后端的 API 可能需要你的 key，也可能产生少量费用。缺 key 的后端我会先跳过并告诉你，不会自己去注册。
- 15 次生成的结果会有随机性，样本不大，结论只作参考，不是严格基准测试。
