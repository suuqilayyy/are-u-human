# are u human · 故事与设计依据

CPX 2026 Track 2（Reverse UX）。持续更新，记录已经定下的故事前提和它们的理由。

## 核心问题

AI 越来越擅长用人类的媒介以假乱真的时候，人类怎么证明自己是人？再往前一步：人相对数字智慧的独特性是什么？人需不需要证明自己的存在？

## 世界

2040 年，个人 Agent 替人选课、发邮件、买东西、回消息。Neverland 是一个只允许真人进入的论坛（90 年代个人主页风格），守门的是一个叫 Gate 的 AI 验证系统（现代毛玻璃界面），两种质感的断裂本身就在说"这扇门不是社区里的人做的"。

## 为什么不能用政府 ID（2026-11-21 定）

两个原因都成立：

1. **ID 证明的是身份，不是在场。** 个人 Agent 本来就合法地拿着你的身份办事，ID 和刷脸它都能过（深度伪造已经能骗过视频认证）。Neverland 要知道的是：此刻在打字的是你本人，还是你的 Agent。这件事没有证件能回答，只能看此刻的行为，而行为恰恰可以被模仿。
2. **Neverland 是想不经代理、甚至匿名说话的地方。** 交出护照，就把它变成了政务系统。

由此 Gate 验证的是"在场"，开场文案方向：*"Your agent already has your ID. We need you."*

## 持续在场（2026-11-21 提出）

验证不是一次性的。像防自动化程序那一套一样，系统要一直知道"你还是你"：进入论坛后，人必须一直开着摄像头和麦克风，由 Agent 判断连续性。人为了证明自己是人，要一直被看着才能正常使用。
